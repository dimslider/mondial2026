# 📺 שלט לטלוויזיה – שלט אוניברסלי חינמי לאנדרואיד

שלט רחוק לטלוויזיות חכמות, דרך ה-Wi-Fi הביתי. בלי פרסומות, בלי חשבון ובלי שרתים חיצוניים: הטלפון מדבר ישירות עם הטלוויזיה.

| טלוויזיה | דגמים | צימוד ראשון |
|---|---|---|
| **Samsung** | Tizen, משנת 2016 ואילך (כולל QLED) | אישור **Allow** בטלוויזיה |
| **LG** | webOS, משנת 2014 ואילך | אישור **Accept** בטלוויזיה |
| **Android TV / Google TV** | TCL, Sony, Xiaomi, Philips, Hisense (דגמי Google TV), Chromecast, Mi Box ועוד | קוד בן 6 תווים שמופיע בטלוויזיה ומקלידים בטלפון |

## הורדה והתקנה

1. בטלפון האנדרואיד פתחו את הקישור (מומלץ ב-Chrome):
   **https://github.com/dimslider/mondial2026/releases/latest/download/TV-Remote.apk**
2. פתחו את הקובץ שירד. אם אנדרואיד שואל – אשרו "התקנה ממקורות לא ידועים".
3. אם Play Protect מזהיר – "פרטים נוספים" ← "התקן בכל זאת".
4. פתחו את "שלט לטלוויזיה". האפליקציה סורקת את הרשת ומזהה לבד את סוג הטלוויזיה.
5. בחיבור הראשון: בסמסונג ו-LG מאשרים בטלוויזיה; ב-Android TV מקלידים בטלפון את הקוד שעל המסך.

עדכון לגרסה חדשה: מורידים שוב מאותו קישור ומתקינים מעל הקיימת. ההגדרות והצימוד נשמרים.

## הדלקת טלוויזיה כבויה

- **Samsung:** הגדרות ← כללי ← רשת ← הגדרות מומחה ← **הפעלה עם נייד (Power On with Mobile)**.
- **LG:** להפעיל **TV On With Mobile / הדלקה דרך Wi-Fi** (בהגדרות ← כללי ← התקנים; המיקום משתנה לפי הדגם).
- **Android TV:** עובד כשהטלוויזיה נשארת מחוברת לרשת במצב המתנה (ברירת המחדל ברוב דגמי Google TV).

## מה יש בשלט

- ווליום, השתקה, ערוצים, הדלקה/כיבוי, הגדרות, חיצים + OK או משטח מגע, מספרים, כפתורים צבעוניים ועוד
- **כמה טלוויזיות בבית** – מעבר מהיר בין "סלון", "חדר ילדים" וכו' (לחיצה על שם הטלוויזיה למעלה)
- **כפתורי קיצור לאפליקציות** – לחיצה ארוכה על כפתור קיצור בוחרת איזו אפליקציה הוא פותח
- **חיפוש קולי** והקלדת טקסט לטלוויזיה
- **טיימר שינה** – הטלוויזיה נכבית לבד אחרי 15–120 דקות
- **מצב פשוט** – פחות כפתורים וכפתורים גדולים, לילדים ולמבוגרים
- **גישה מהירה מחוץ לאפליקציה** (בהגדרות):
  - כפתורי שליטה בהתראות ובמסך הנעילה
  - כפתורי הווליום של הטלפון שולטים בטלוויזיה גם כשהאפליקציה סגורה (רק כשהטלוויזיה מחוברת)
  - השתקה או עצירה אוטומטית של הטלוויזיה כשנכנסת שיחה
  - ווידג'ט למסך הבית וכפתורים להגדרות המהירות ("שלט", "השתק TV")
- בלי פרסומות, בלי מעקב, בלי חשבון – הכול נשאר ברשת הביתית

## פתרון בעיות

- **"לא נמצאה טלוויזיה"** – ודאו שהטלוויזיה דלוקה ושהטלפון על אותה רשת Wi-Fi (לא רשת אורחים). אפשר להזין IP ידנית.
- **"החיבור נדחה"** – לחצו על שורת הסטטוס כדי לנסות שוב, או "צמד מחדש" בהגדרות.
- **Android TV לא מציג קוד** – בטלוויזיה: הגדרות ← אפליקציות ← אפליקציות מערכת ← Android TV Remote Service ← נקה נתונים, ואז "צמד מחדש".

## למפתחים

- `app/` – אפליקציית האנדרואיד. ממשק ב-WebView (`assets/remote.html`), חיבור לטלוויזיה ב-Kotlin:
  `SamsungDriver` (WebSocket 8002), `LgDriver` (SSAP, 3001/3000), `AndroidTvDriver` (Android TV Remote v2, TLS 6466/6467).
- `jvm-tests/` – בדיקות לפרוטוקולים מול טלוויזיות מדומות: `gradle -p jvm-tests test`.
- GitHub Actions (`.github/workflows/samsung-remote.yml`) מריץ את הבדיקות, בונה APK ומפרסם Release בכל שינוי.
