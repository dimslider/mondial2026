# 📺 שלט לטלוויזיה – אפליקציית אנדרואיד חינמית

אפליקציית שלט רחוק לטלוויזיות סמסונג חכמות (Tizen, משנת 2016 ואילך, כולל QLED Q60T).
עובדת דרך ה-Wi-Fi הביתי, ללא פרסומות, ללא חשבון, ללא שרתים חיצוניים – הטלפון מדבר ישירות עם הטלוויזיה.

## הורדה והתקנה

1. בטלפון האנדרואיד פתחו את הקישור:
   **https://github.com/dimslider/mondial2026/releases/latest/download/TV-Remote.apk**
2. פתחו את הקובץ שירד. אם אנדרואיד שואל – אשרו "התקנה ממקורות לא ידועים" עבור הדפדפן/הקבצים.
3. אם Play Protect מזהיר ("אפליקציה לא מוכרת") – בחרו "פרטים נוספים" ← "התקן בכל זאת".
4. פתחו את "שלט לטלוויזיה". האפליקציה תחפש את הטלוויזיה ברשת לבד.
5. **בפעם הראשונה** תופיע הודעה על מסך הטלוויזיה – צריך לבחור בה **Allow / אפשר**. אין שלט? יש שתי דרכים:
   - בעזרת אפליקציית השלט הישנה (עם הפרסומות), שעדיין מחוברת: חיצים עד Allow ואז OK.
   - בעזרת הכפתור הפיזי שמתחת למרכז המסך: לחיצה קצרה עוברת בין אפשרויות, לחיצה ארוכה בוחרת.
   אחרי האישור הראשון – כל פתיחה של האפליקציה מתחברת אוטומטית. כל טלפון חדש יצטרך אישור פעם אחת.

שלחו את הקישור לשאר בני הבית – כל טלפון מתחבר בנפרד.

## כדי שכפתור ההדלקה ידליק טלוויזיה כבויה

בטלוויזיה: **הגדרות ← כללי ← רשת ← הגדרות מומחה ← הפעלה עם נייד (Power On with Mobile) ← מופעל**.
(הכיבוי עובד תמיד; ההדלקה מתבצעת ב-Wake-on-LAN ודורשת את ההגדרה הזו.)

## מה יש בשלט

- ווליום, השתקה, ערוצים, הדלקה/כיבוי, הגדרות טלוויזיה
- חיצים + OK, או מצב משטח מגע (החלקה לכיוון, הקשה = OK)
- חזור, בית, נגן/השהה/קדימה/אחורה
- מקשי מספרים וכפתורים צבעוניים, מקור/HDMI, מידע, מדריך, כתוביות ועוד
- Netflix, Spotify, YouTube בלחיצה, ורשימת כל האפליקציות שמותקנות בטלוויזיה
- הקלדת טקסט לטלוויזיה (לחיפוש ביוטיוב וכו')
- כפתורי הווליום הפיזיים של הטלפון שולטים בווליום של הטלוויזיה (ניתן לכבות בהגדרות)
- לחיצה ארוכה = חזרה (למשל ווליום)

## פתרון בעיות

- **"לא נמצאה טלוויזיה"** – ודאו שהטלוויזיה דלוקה ושהטלפון על אותה רשת Wi-Fi (לא נתונים סלולריים / רשת אורחים). אפשר להזין IP ידנית בהגדרות.
- **"החיבור נדחה"** – בטלוויזיה: הגדרות ← כללי ← מנהל התקנים חיצוניים ← מנהל חיבור התקנים ← רשימת התקנים, ואפשרו את "Home Remote". ואז "צמד מחדש" באפליקציה.

## בנייה

האפליקציה נבנית אוטומטית ב-GitHub Actions (`.github/workflows/samsung-remote.yml`) בכל שינוי בתיקייה הזו, ומתפרסמת כ-Release.
בנייה מקומית: `gradle assembleRelease` (Gradle 8.9, JDK 17, Android SDK 34).
