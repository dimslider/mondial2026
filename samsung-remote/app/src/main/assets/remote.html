הקלדה לטלוויזיה

פתח קודם שדה חיפוש בטלוויזיה (למשל ביוטיוב), ואז הקלד כאן.

אפליקציות בטלוויזיה

חיבור לטלוויזיה

טלוויזיות ברשת

או הזן כתובת IP ידנית

כתובת ה-IP מופיעה בטלוויזיה תחת: הגדרות ← כללי ← רשת ← מצב רשת.

הגדרות

פתרון בעיות

• בחיבור הראשון תופיע בטלוויזיה הודעה – בחר Allow / אפשר.
• כדי שכפתור ההדלקה ידליק טלוויזיה כבויה: בטלוויזיה הפעל
  הגדרות ← כללי ← רשת ← הגדרות מומחה ← הפעלה עם נייד (Power On with Mobile).
• הטלפון והטלוויזיה חייבים להיות מחוברים לאותה רשת Wi-Fi.
