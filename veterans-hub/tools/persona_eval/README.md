# בדיקת התאמה מול פרופילים

שבעה פרופילים בדיוניים מלאים (שוטר בתהליך הכרה, לוחם ותיק מוכר, מילואימניק עם פגיעת ראש, שוטר דרוזי מהצפון, לוחמת משוחררת, בת זוג של מילואימניק, אב שכול), כל אחד בשתי גרסאות מילוי (מלאה ומינימלית).
לכל פרופיל יש רשימת זהב שנבנתה "עיוורת" ע"י בודק קליני: A = שלוש התחנות הנכונות, B = עוד רלוונטיים, C = אסור שיופיעו.
ב-review_*.md: הביקורת המלאה, מה מוצאים לבד בגוגל, ומה חסר במאגר.

הרצה (אחרי כל שינוי באלגוריתם או בנתונים):

    python3 tools/persona_eval/eval.py

המדדים: A בתחנות, A+B בעשרה הראשונים, A+B בכל הרשימה, C ברשימה (ובתחנות), אורך. TOTAL גבוה = טוב.
לפני התיקונים (2026-10-08): 8.9. אחרי: 63.3. אחרי שאלות ההמשך (החמרה, תקופת שירות, גיל): 66.8.

עם 7 פרופילים (אחרי תיוג מובנה, מרחק לפי יישוב, שאלת 'מה הכי חשוב' ושאלת הקשר המשפחתי): לפני 48.2, אחרי 111.5.
