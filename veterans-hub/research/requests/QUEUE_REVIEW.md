# בדיקת התור מעמוד הניהול

1. עידו מוריד מעמוד הניהול, בלשונית "סנכרון עם Claude", את הקובץ `azimut-queue-YYYY-MM-DD.json` ושולח אותו. בקובץ אין פניות "שיחזרו אליי" ואין פרטי קשר.
2. Claude בודק כל פריט מול `data/services.js` ומחזיר דוח עם המלצה לכל פריט:
   - **מקום חדש:** קיים (באיזה מזהה) / כפילות / חדש ומתאים (עם תיוג מלא לפי RUBRIC) / לא מתאים.
   - **תיקון או זמינות:** נכון ולעדכן / כבר מעודכן / לא אמין.
   - **משוב ודירוג:** מה לומדים מזה ומה לשנות באלגוריתם או בתוכן.
3. אחרי שעידו מאשר: מקומות חדשים נכנסים ל-`research/community/community_adds.json` עם תיוג מלא, ותיקונים ל-`research/community/corrections.json`. בונים, בודקים ודוחפים.
4. Claude מחזיר קובץ החלטות, ועידו מייבא אותו באותה לשונית כדי לסגור את מה שטופל:
```json
{"decisions": [{"ids": [11], "action": "done", "note": "נוסף למאגר"}, {"ids": [12, 13], "action": "reject", "note": "כפילות"}]}
```
