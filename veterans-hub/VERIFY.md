# אימות המאגר מול המקורות

הנתונים שב-`data/services.js` נאספו במקור מתקצירי תוצאות חיפוש. שירות מסומן "מאומת" רק אחרי שהתוכן שלו נקרא מול האתר של הגוף עצמו.

## מצב נוכחי (אימות 7.10.2026)

- 291 שירותים לפני האימות → 194 אחרי. 161 מאומתים (התיאור, התנאים, העלות והטלפון תוקנו לפי העמוד הרשמי). 33 לא מאומתים ומוצגים עם אזהרה.
- נמחקו שירותים שנמצאו רק בכתבות, שנסגרו, שעוד לא פועלים, או שאין להם מקור רשמי. אוחדו כפילויות.
- `data/guides.js` נבדק מול shikum.mod.gov.il, btl.gov.il ו-me.health.gov.il. פרטים שאפשר היה לראות רק ב"כל זכות" או באתר המילואים נוסחו באופן כללי.
- kolzchut.org.il, www.gov.il ו-miluim.idf.il חוסמים גישה אוטומטית (Cloudflare), ולכן 33 השירותים שלמטה לא אומתו. אפשר לאמת אותם ידנית בדפדפן, לעדכן את קובץ המחקר, ולהוסיף `"confidence": "high"` ו-`"reviewed_at": "<תאריך>"`.
- באתר אגף השיקום הטקסט נטען ב-JavaScript. `verify_sources.py` קורא אותו דרך ה-API של האתר (`/api/Umbraco/getDynamicPage/?pageId=`).

## איך מסומן "מאומת"

`build_data.py` מסמן `verified_at` לשירות אם יש לו `reviewed_at` בקובץ המחקר (התוכן נקרא ותוקן ידנית מול העמוד הרשמי), או אם הוא ברמת ביטחון `high` ועבר את הבדיקה האוטומטית. בדיקה אוטומטית לבדה לא מסמנת שירות ברמת ביטחון בינונית.

## מה צריך: סשן עם גישה פתוחה לאינטרנט

אפשרות א׳: סביבת ענן חדשה עם גישת רשת מלאה
1. נכנסים בדפדפן ל-https://claude.ai/code. לא באפליקציה, כי שם לא תמיד מוצגת עריכת סביבה.
2. בבורר הסביבה (בכותרת הסשן, או במסך יצירת סשן חדש) בוחרים **Add environment** או עורכים את Default.
3. תחת **Network access** בוחרים **Full**.
   הוראות: https://code.claude.com/docs/en/cloud-environments#network-access
4. פותחים סשן חדש על הריפו `dimslider/mondial2026` בסביבה הזו, ומדביקים את ההנחיה שלמטה.

אפשרות ב׳: Claude Code על המחשב שלך (טרמינל, `npm i -g @anthropic-ai/claude-code`). הגישה לרשת היא של המחשב עצמו, ואין חסימות.

## ההנחיה להדבקה בסשן החדש

```
בענף ccr-d452e790-ntiise, בתיקייה veterans-hub, יש מאגר שירותים לנכי צה"ל ולמילואימניקים.
המאגר נאסף מתקצירי חיפוש בלבד ולא אומת.
1. הרץ: python3 tools/verify_sources.py
2. עבור על research/verification.csv. בכל שורה שנכשלה, וגם בכל שורה שעברה, קרא את
   research/pages/<id>.txt ואת אתר הגוף (WebFetch). תקן ב-research/*.json את התיאור, התנאים,
   העלות, הזכאות, הטלפון והאתר כך שיתאימו בדיוק למה שכתוב באתר הרשמי.
   שירות שנסגר או שלא נמצא לו מקור רשמי: למחוק.
   אל תשאיר אף פרט שלא ראית בעיניים בעמוד.
3. תאמת במיוחד את כל קווי החירום ואת data/guides.js (סכומים, תנאים, תאריכים) מול
   kolzchut.org.il, shikum.mod.gov.il, btl.gov.il ו-miluim.idf.il.
4. הרץ שוב python3 tools/verify_sources.py ואז python3 tools/build_data.py research/*.json
5. commit ו-push לאותו ענף. דווח כמה אומתו, כמה תוקנו וכמה נמחקו.
```

## מה הכלי בודק

`tools/verify_sources.py` נכנס ל-`source_url` ול-`website` של כל שירות ושומר את טקסט העמוד. הוא בודק שהעמוד חי, ששם הגוף מופיע בו, ושמספר הטלפון שבמאגר מופיע בעמוד. אחר כך `build_data.py` מסמן `verified_at` לכל שירות שעבר, והאתר מציג לידו "✓ מאומת".

הבדיקה האוטומטית מוכיחה רק שהמקור קיים ותואם בסיסית. את התוכן עצמו (תנאים, עלויות, זכאות) צריך לקרוא ולתקן, ולכן יש את שלב 2 בהנחיה.
